Introduction

In Python, conditionals control which code runs (branching). Loops repeat actions. Mastering these helps you implement algorithms, process data, validate input, and reason about program complexity.

Overview

  • Conditional and Looping help control how a program executes based on conditions or repeated actions.
  • Help reduce code repetition and improve efficiency.
  • Allow programs to respond dynamically to different inputs.
  • Logic is the soul of programming — and control statements bring it to life.

Conditional Statements

Syntax: if

Structure: if <condition>: followed by an indented block. Python uses indentation (4 spaces recommended) instead of braces.

# if example
x = 10
if x > 5:
    print("x is greater than 5")
# Output:
# x is greater than 5
Explain: condition evaluates to True/False. If True -> run indented block.

Syntax: if-else

# if-else example
num = 8
if num % 2 == 0:
    print("Even")
else:
    print("Odd")
# Output:
# Even
Explain: else runs when the if condition is False.

Syntax: if-elif-else (chained)

# grades example
marks = 85
if marks >= 90:
    print("A")
elif marks >= 75:
    print("B")
else:
    print("C")
# Output:
# B
Explain: first matching branch executes; others are skipped.

Advanced Conditionals

Logical operators & truthiness

# logical operators
a = 5
b = 0
if a >0 and b==0:
    print("a positive and b zero")
# Output:
# a positive and b zero

# truthiness example
s = ""
if not s:
    print("empty string is falsy")
# Output:
# empty string is falsy
Explain: Python treats empty container/zero/None/False as falsy.

Nested conditionals

# nested example
age = 20
if age >= 18:
    if age >= 21:
        print("adult (21+)")
    else:
        print("adult (18-20)")
else:
    print("minor")
# Output:
# adult (18-20)

match-case (Python 3.10+)

# match-case example
day = 3
match day:
    case 1: print("Mon")
    case 2: print("Tue")
    case 3: print("Wed")
    case _: print("Other")
# Output:
# Wed

Looping — Basics

for loop (iterate sequence)

# simple for
for i in range(1,6):
    print(i)
# Output:
# 1
# 2
# 3
# 4
# 5
Explain: range(start, stop) is stop-exclusive. Use range(1,6) to get 1..5.

for with step and list iteration

# with step
for i in range(0,10,2):
    print(i)
# Output:
# 0
# 2
# 4
# 6
# 8

# iterate list
names = ["Anna","Ben","Cara"]
for name in names:
    print("Hello", name)
# Output:
# Hello Anna
# Hello Ben
# Hello Cara

while loop (condition-driven)

# while example
count = 1
while count <= 5:
    print(count)
    count += 1
# Output:
# 1
# 2
# 3
# 4
# 5

Advanced Looping Topics

Nested loops

# nested example
for i in range(1,4):
    for j in range(1,4):
        print(i, j)
# Output:
# 1 1
# 1 2
# 1 3
# 2 1
# 2 2
# ...
Complexity: nested loops often mean O(n × m). Be careful with large inputs.

break and continue

for i in range(1,6):
    if i == 3:
        continue  # skip printing 3
    if i == 5:
        break     # stop loop early
    print(i)
# Output:
# 1
# 2
# 4
Explain: continue jumps to next iteration; break exits the loop entirely.

else clause on loops (Python-specific)

# loop else
for i in range(3):
    print(i)
else:
    print("loop finished normally")
# Output:
# 0
# 1
# 2
# loop finished normally

# if break occurs, else is skipped
Explain: else runs when loop completes without break.

Common Pitfalls & Best Practices

  • Off-by-one: remember Python range(stop) excludes stop. Test small cases.
  • Infinite loops: always ensure loop conditions change (or include a safe break).
  • Mutable defaults (function args): avoid mutable default arguments for functions.
  • Deep nesting: if code gets hard to read, extract functions — one responsibility per function.

Example — common infinite loop mistake & fix

# BAD — missing update -> infinite loop
count = 0
while count < 3:
    print(count)
    # missing count += 1    <-- infinite loop

# GOOD — add update
count = 0
while count < 3:
    print(count)
    count += 1
# Output:
# 0
# 1
# 2

Practice — Real-world Mini Problems (Python)

1 — Factorial (using loop)

Problem: compute n! for n = 5

def factorial(n):
    result = 1
    for i in range(1, n+1):
        result *= i
    return result

print(factorial(5))
# Output:
# 120
Explain: loop multiplies numbers 1..n. O(n) time.

2 — Check palindrome (using conditionals)

def is_palindrome(s):
    s = ''.join(ch.lower() for ch in s if ch.isalnum())  # normalize
    return s == s[::-1]

print(is_palindrome("Madam"))      # True
print(is_palindrome("Hello"))      # False
# Output:
# True
# False
Explain: clean string, then compare with reversed string.

3 — Count vowels (loop + conditional)

def count_vowels(s):
    s = s.lower()
    count = 0
    for ch in s:
        if ch in "aeiou":
            count += 1
    return count

print(count_vowels("Education"))  # Output: 5
